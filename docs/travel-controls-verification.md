# Development itinerary improvements

Per-leg transport choices (walking, driving, cycling, transit) and manual whole-minute durations are saved on the destination entry with its preceding entry ID. Offline edits use the existing IndexedDB queue, version checks and server permissions. Reordering or moving a plan does not silently apply a duration to a different origin. Manual minutes support 0–10080, and a separate Save time button commits edits.

Calculate travel time uses the authenticated Routes endpoint with the preceding activity's end instant, respecting its time zone. Google results remain in component memory only and are labeled live estimates; manual durations are retained. Missing places, disconnected network and service failures offer manual recovery. The map draws each leg with its saved mode. Schedule checks use manual times or rough mode-specific estimates; live estimates show a separate conflict check next to the leg. Multiday lodging stays do not create a spurious travel deadline.

All time inputs use explicit hour/minute/AM-PM controls and store the existing 24-hour local representation. Timeline, stay end times and route proposals display 12-hour times. Activity forms show search, title, type, date, start time, duration and notes; advanced fields remain in a native keyboard-accessible details disclosure. Hidden existing values are preserved on save.

The route optimizer still uses the transport selected inside its preview dialog for the whole proposed route. It does not optimize mixed-mode/manual-duration legs. Live estimates are requested explicitly to avoid a billable request for every edit. Transit and driving estimates depend on the departure date and Google availability; past dates may be rejected and surfaced to the user.

Verification: automated tests cover route mode/departure, manual save and reset, route error recovery, viewer restrictions, origin changes, midnight/noon/afternoon input, warning durations, advanced field preservation, map leg mode and multiday lodging. Existing money, server permissions, offline/sync and navigation suites also pass. Local isolated demo browser verification confirmed manual time saved at 45 minutes, AM/PM timeline display and optional activity fields expanding correctly. Live authenticated Google calls were mocked in tests; no private production records were altered. Changes are development-only and have not been pushed to production.
